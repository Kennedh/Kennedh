## 📌 Projetos em destaque

### [SysPulse](https://github.com/Kennedh/sys-pulse)

Aplicação desktop para monitoramento de recursos do computador em tempo real, incluindo CPU, RAM, GPU, disco, processos, rede e latência.

**Destaques:** PySide6, QThread, psutil, GPUtil, processamento assíncrono e Model-View.

---

### [Compress Image Pro](https://github.com/Kennedh/Compress_Image)

Ferramenta desktop para compressão, redimensionamento e conversão de imagens, com preview, diferentes formatos e processamento em segundo plano.

**Destaques:** Python, Pillow, CustomTkinter, manipulação de arquivos e multithreading.

---

### [Compressor de PDF](https://github.com/Kennedh/Compress_pdf)

Automação em Python para compactação de PDFs utilizando Ghostscript e diferentes níveis de compressão conforme o cenário de uso.

**Destaques:** Python, subprocess, argparse, automação e integração com ferramenta externa.

---

### [Sistema de Gestão de Livraria](https://github.com/Kennedh/livraria)

Aplicação para gestão de livros, estoque, clientes, vendas e relatórios, com regras de negócio e persistência local.

**Destaques:** Python, POO, Tkinter, JSON, arquitetura modular e tratamento de exceções.
