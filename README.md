## Projetos no GitHub

- **SysPulse** — Aplicação desktop que monitora e registra o uso de recursos e processos do computador. Permite consultar picos de utilização e exportar relatórios da sessão. Desenvolvida com Python, PySide6 e psutil. [Ver repositório](https://github.com/Kennedh/sys-pulse)
- **Compress Image Pro** — Ferramenta desktop para comprimir, redimensionar e converter imagens, com pré-visualização, controle de qualidade e processamento em segundo plano. Desenvolvida com Python, Pillow e CustomTkinter. [Ver repositório](https://github.com/Kennedh/Compress_Image)
- **Compressor de PDF** — Utilitário para compactar PDFs com diferentes níveis de compressão, conforme o tamanho e a qualidade desejados. Desenvolvido com Python e Ghostscript. [Ver repositório](https://github.com/Kennedh/Compress_pdf)
- **Sistema de Gestão de Livraria** — Aplicação para gerenciar livros, estoque, clientes, vendas e relatórios, com regras de negócio e persistência local. Desenvolvida com Python, Tkinter e JSON. [Ver repositório](https://github.com/Kennedh/livraria)
